# SophriaConst

A modern, high-performance website built with **Next.js 15 (App Router)**, **React 18**, and **TypeScript** for **Sophria Private Limited** — an architectural renovation and master flooring design-build firm based in Mississauga, Ontario & the Greater Toronto Area.

## Features

- **Next.js 15 App Router**: Server-side rendering, static optimization, and modular routing.
- **Interactive Before & After Slider**: Real-time touch and drag space comparison.
- **Re-media Video Showcase**: Ultra-smooth on-site video reels modal preview.
- **AI Room Visualizer Integration**: Direct in-room flooring visualizer preview.
- **Mobile-First Responsive Layout**: Floating pill navigation, centered branding, zero layout shifts.

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Deployment

Optimized for **Vercel** deployment with zero configuration.
